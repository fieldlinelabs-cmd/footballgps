## 3. FootballGPSの位置づけ

**強み**
- 専用の端末を買わずに、ヒートマップ、軌跡の再生、サードの割合、キレスコアまで見られる（個人向けでここまで見られる競合は確認できなかった）
- AI監督フィードバック（競合に見当たらない最大の差別化点。ただし公開時は非表示、`docs/広告仕様書.md` §7）
- 無料（広告モデル）。競合は月額課金か端末の購入が必要

**弱み・リスク**
- 公式戦では腕時計を着けられないことが多い（§6.1）
- 専用端末と比べてGPSを測る頻度が少なく、最高速度・スプリントの精度で不利になりやすい
- 心拍・体力の指標が競合より少ない（§7）
- チーム機能がない

## 5. 子どもの利用（検討事項4）

**対応する利用構成:** `docs/機能仕様書.md` §12の6

| 構成 | 扱い |
|---|---|
| ① 子ども用のiPhoneとWatchがある | 対応 |
| ② ①と同じだが、iPhoneにSIMがない | 対応 |
| ③ 子どものWatchを親のiPhoneとペアリング | 親がFootballGPSを使わない場合のみ対応。プロフィールに子どもの情報を入れるよう案内する |
| ④ ファミリー共有設定（Apple Watch For Your Kids）だけ | 非対応 |

**③について分かったこと:**
- 子どものWatchの心拍・歩数などが親のヘルスケアに入るのは、Apple Watchのペアリングの仕組みによるもので、FootballGPSとは関係なく起きる。FootballGPSはワークアウトをヘルスケアに保存していない
- ヘルスケアは複数のWatchのデータを1人分として扱い、時間帯が重なるところは優先順位で1つを選び、重ならないところはほかのソースで補うと考えられる（公式ページは優先順位のみ明記、補完は利用者の報告からの推定）
- Appleは1台のiPhoneを複数人で使うことを想定しておらず、iPhoneを持たない子どもには④を用意している
- 何もしない場合の体験: 親がFootballGPSを使わずプロフィールが子どもの情報なら問題なし。プロフィールが親のままだと年齢で決まるもの（スプリントの閾値、AI機能の18歳の判定、13歳未満の広告タグ）がずれる。親も使うと親子のセッションと集計が混ざり、救えない

**年齢に関する決定:**

| 決定 | 記載先 |
|---|---|
| AI機能は18歳以上に限定（Gemini APIの規約が18歳未満の利用者を想定するアプリでの利用を禁じている） | `docs/広告仕様書.md` §7.6 |
| 13歳未満の利用者には広告に子ども向けのタグを付ける（年齢層が混在するアプリの一般的なやり方） | `docs/広告仕様書.md` §10.3 |
| 13歳未満のスプリントの閾値を50代と同じにする（実装済み） | `docs/技術実装仕様書.md` §13.4.0 |

## 6. 売り方（検討事項3）

### 6.1 前提: 公式戦での腕時計

- 競技規則第4条（競技者の用具）で、安全のため装身具はすべて禁止。条文に「腕時計」とは書かれていないが、装身具として外させるのが一般的な運用
- 試合で着用する追跡用の端末にはFIFAの安全基準がある。Apple Watchは対象外
- **「公式戦では使えない」と正直に伝える。** 使える場面は、練習、練習試合、個人のトレーニング、主催者が認める草サッカーやフットサル。チームの練習で着けてよいかはチームしだい

### 6.2 ターゲット（2026-10-29決定）

| 優先 | ターゲット | 理由 |
|---|---|---|
| **主** | **社会人・シニアのアマチュア選手** | Apple Watchの所有者が多い年代。公式戦が少なく練習や草サッカーが中心なので、公式戦で使えない弱点が気にならない。年齢・性別に合わせた基準や「一般・シニア」の選手カテゴリがすでにある。AI機能の年齢制限の影響を受けない |
| 次 | 中高生（部活・クラブ） | 自分のiPhoneを持っている。成長の推移やバッジなどが合う。Knowsで分かるとおりデータへの関心がある。ただしWatchの所有者は少なく、練習で着けられるかは指導者しだい。AI機能は使えない |
| 案内のみ | 保護者（小学生の子ども） | ③の条件付きでのみ対応 |

### 6.3 訴求ポイント（2026-10-29決定、優先順）

| # | 訴求 | 支える機能 |
|---|---|---|
| 1 | 今あるApple Watchだけで、自分のサッカーが見える | Watchで記録、iPhoneで分析。追加の端末なし、無料 |
| 2 | どこにいて、いつ、どれだけ走ったか | ヒートマップ、軌跡の再生、サードの割合、時間帯別の運動量、スプリント、キレスコア |
| 3 | 年齢に合った基準で、成長や「維持」が分かる | 年齢・性別に合わせたスプリントの基準、統計の推移、今日の出来 |
| 4 | 続ける楽しみ | レベル、バッジ、プレイヤータイプ、プロスタイル診断 |

- 中高生には3と4を前に出す
- **売りにしないもの:** 公式戦での使用、精度の高さ（参考値扱い）、AI監督フィードバック（有効にした後で加える）、チームでの管理、心拍（強化後に加える、§7）

### 6.4 App Storeのページ（2026-10-29決定）

| 項目 | 内容 |
|---|---|
| 名前 | FootballGPS - サッカー記録 |
| サブタイトル | Apple Watchで自分のサッカーを振り返る |
| プロモーション用テキスト | いつものApple Watchで、走った距離、いた場所、スプリントまで記録。草サッカーや練習の後に、ヒートマップと動いた軌跡で自分のプレーを振り返りましょう。年齢に合った基準で、成長も分かります。 |
| 検索キーワード | ヒートマップ,走行距離,スプリント,フットサル,トラッカー,練習,草サッカー,ポジション,運動量,スタミナ,心拍,分析,成長 |

- 名前は「FootballGPS」の英語名を残し、日本で検索される「サッカー」を加えた
- **サブタイトルの「Apple Watch」:** 名前には入れられないが説明文には入れられる（Appleの以前の開発者向けページ）。サブタイトルについては公式の決まりが見つからなかった。**そのまま申請し、審査で指摘されたら直す**（例:「腕時計ひとつで、自分のサッカーを振り返る」）
- 書き方は「Apple Watch」（2語、AとWを大文字）

**説明文:**

```
いつものApple Watchが、あなた専用のサッカーGPSトラッカーになります。
専用の端末は必要ありません。練習や草サッカーの後に、iPhoneで自分のプレーを振り返りましょう。

■ どこにいて、いつ、どれだけ走ったか
・ヒートマップで、ピッチのどこにいたかが一目で分かります
・動いた軌跡を、試合の流れに沿って再生できます
・守備・中盤・攻撃のどのエリアにいたかを割合で表示します
・時間帯ごとの運動量で、後半に落ちていないかが分かります
・スプリントの回数と、方向転換のキレも記録します

■ 年齢に合った基準で、成長が分かる
・年齢と性別に合わせて、スプリントの基準を自動で調整します
・直近の平均と比べて、今日の出来が分かります
・走行距離やスプリントの推移をグラフで確認できます

■ 続ける楽しみ
・レベルとバッジで、日々の活動が積み重なります
・プレイヤータイプやプロスタイル診断で、自分の特徴が分かります

■ 使い方
1. iPhoneで、使うグラウンドの4隅を地図上で登録します
2. Apple Watchで記録を開始し、プレーします
3. 終わったら記録を終了。iPhoneに自動で届きます

■ ご注意
・公式戦では、腕時計は装身具として外すのが一般的です。練習、練習試合、個人のトレーニングなどでお使いください。着用できるかは、チームや大会の決まりに従ってください
・ペアリングしたiPhoneが必要です。ファミリー共有設定のApple Watchには対応していません
・お子さまがお使いになる場合は、プロフィールにお子さまの生年月日と性別を入れてください
・1台のiPhoneで、複数人の記録を分けて管理することはできません
・GPSの精度は、天候や周囲の環境によって変わります。数値は目安としてお使いください

■ 必要なもの
・iOS 26以降のiPhone
・watchOS 26以降のApple Watch

無料でお使いいただけます（広告が表示されます）。
```

**スクリーンショットの順番（iPhone）:**

1. ヒートマップ（見出し:「どこにいたか、一目で」）
2. 軌跡の再生（「動きを、もう一度」）
3. サードの割合と時間帯別の運動量（「後半、落ちていない？」）
4. 統計の推移と今日の出来（「年齢に合った基準で、成長が分かる」）
5. レベル・バッジ、プレイヤータイプ（「続けるほど、楽しくなる」）
6. Watchの記録中の画面（「記録はWatchだけ」）

Apple Watch用には、記録中とサマリーの画面を別に用意する。

### 6.5 名前の権利の確認

- Webを検索した範囲では、「FootballGPS」「Football GPS」「フットボールGPS」の商標の登録・出願は見つからなかった。App Storeにも同じ名前のアプリは見つからなかった
- 「Football」「GPS」は商品の内容を表す一般的な言葉で、日本の商標法（第3条1項3号）では言葉だけの名前は登録が認められにくい。他者が独占的な権利を持っている可能性は低い。逆に、FootballGPS自体も商標として守られにくい
- **未確認:** J-PlatPat（https://www.j-platpat.inpit.go.jp/）での検索。「FOOTBALLGPS」「FOOTBALL GPS」「フットボールGPS」「フットボールジーピーエス」を、9類・41類・42類で確認する（ユーザーが実施）
- Watchのホーム画面の名前を「FootballGPS Watch App」から「FootballGPS」に変更した（2026-10-29、`CFBundleDisplayName`）

## 7. 心拍・体力の指標（別枠）

**競合の体験（ストアの説明と同種アプリの一般的な作りからの推定）:** プレー中にWatchで心拍とゾーンを表示、試合後にゾーンごとの時間と心拍の推移グラフ、翌日以降に負荷と安静時心拍・HRVから疲労と回復の目安、長期でVO2Maxの推移。

**FootballGPSの現状（2026-10-29時点）:**

| 体験 | 状態 |
|---|---|
| プレー中に心拍を見る（Watch） | × |
| 心拍数の表示 | △（セッション終了時点の値が1つだけ） |
| 消費カロリー | ○ |
| 高強度の割合（最大心拍の80%以上の時間の割合）、高強度スプリント回数 | ○ |
| 高強度の割合の推移 | ○ |
| 時間帯ごとのスタミナ低下 | ○（心拍ではなく運動量から計算） |
| ゾーンごとの時間、心拍の推移グラフ | × |
| 疲労と回復、VO2Max | × |

**強化案（作りやすい順、後日具体化）:**

1. 心拍の推移グラフとゾーンごとの時間（保存済みのデータで作れる。時間帯別の運動量と重ねれば競合より深い体験になる）
2. AI監督フィードバックに心拍の情報を渡す
3. プレー中のWatchに心拍を表示する
4. 疲労・回復とVO2Max（ヘルスケアの読み取り権限の追加が必要で規模が大きい）
- 「終了時点の心拍数」は意味が分かりにくい。平均心拍と最大心拍に置き換えるだけでも改善する
