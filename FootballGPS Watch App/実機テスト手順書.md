# 📝 Apple Watch GPS トラッキングアプリ - 実機テスト手順書

作成日: 2026年3月1日  
対象: FootballGPS アプリ  
目的: WatchConnectivityとGPS計測の動作確認

---

## 📋 事前準備

### **必要なデバイス**
- ✅ Apple Watch (watchOS 10.0以降)
- ✅ iPhone (iOS 17.0以降)
- ✅ 両デバイスがペアリング済み
- ✅ 両デバイスのバッテリーが十分に充電されている

### **必要な設定**
- ✅ iPhoneとApple Watchがペアリングされている
- ✅ 両デバイスでアプリがインストール済み
- ✅ 位置情報の許可が有効
- ✅ HealthKitの許可が有効

### **アプリのインストール方法**
1. Xcodeでプロジェクトを開く
2. スキーム: `FootballGPS` を選択
3. デバイス: あなたのiPhoneを選択
4. ▶️ Run をクリック → iPhoneにインストール
5. スキーム: `FootballGPS Watch App` に変更
6. デバイス: あなたのApple Watchを選択
7. ▶️ Run をクリック → Apple Watchにインストール

## 🧪 テスト1: クイックデータ送信テスト (所要時間: 2分)

**目的:** WatchConnectivityが正常に動作するか確認

### **手順:**

#### **ステップ1: アプリの起動**
1. **iPhoneでアプリを起動**
   - ホーム画面から「FootballGPS」をタップ
   - 「セッション」タブが表示される
   - 現在のセッション数を確認・記録する (例: 3件)
   - ⚠️ **重要**: iPhoneアプリは**起動したまま**にしてください（バックグラウンドでもOK）

2. **Apple Watchでアプリを起動**
   - ホーム画面から「FootballGPS」をタップ
   - メイン画面が表示される

#### **ステップ2: テストデータの送信**
1. Apple Watchで **「テスト送信」ボタン**(オレンジ色)をタップ
2. シートが開く
3. **「送信」ボタン**(青色)をタップ
4. 2秒待つ
5. 結果メッセージを確認:
   - ✅ **「送信成功! iPhoneで確認してください」** → 成功!
   - 📦 **「キューに追加 後で自動送信されます」** → 成功(数秒待つ)
   - ⚠️ **「WatchConnectivity未初期化」** → 失敗(再試行)

#### **ステップ3: iPhoneで確認**
1. **「閉じる」をタップ**してシートを閉じる
2. iPhoneアプリに戻る
3. ⏳ **10秒ほど待つ**（データ受信を待機）
4. **画面を下に引っ張って更新**（Pull to Refresh）
5. **「セッション」タブ**を確認
6. セッション数が **1件増えている**か確認 (例: 3件 → 4件)
   - ❌ **増えていない場合**: 
     - iPhoneアプリを**完全に終了**してから再起動
     - または、さらに30秒待ってから再度確認
7. 一番上の新しいセッションをタップ
   - タイトル: **「テスト送信 - XX:XX」**
   - 距離: 約850m
   - 時間: 10分

#### **ステップ4: ヒートマップの確認**
1. セッション詳細画面で **「ヒートマップ」タブ**をタップ
2. フィールド上に色付きのヒートマップが表示される
3. 凡例(カラーバー)が表示される
4. フィールドライン(ハーフウェイライン、ペナルティエリアなど)が表示される

### **✅ 成功基準:**
- [ ] Apple Watchで「送信成功」または「キューに追加」が表示される
- [ ] iPhoneのセッション数が1件増える
- [ ] 新しいセッション「テスト送信 - XX:XX」が表示される
- [ ] ヒートマップが正しく表示される

### **❌ 失敗時の対処:**
- WatchConnectivity未初期化の場合:
  - 両方のアプリを完全に終了
  - iPhoneを再起動
  - Apple Watchを再起動
  - 再度テスト

## 🏃 テスト2: 室内での短時間ワークアウトテスト (所要時間: 5分)

**目的:** GPS計測とデータ記録の基本動作を確認

### **手順:**

#### **ステップ1: ワークアウトの開始**
1. Apple Watchでアプリを起動
2. **「開始」ボタン**(緑色)をタップ
3. 許可ダイアログが表示されたら **「許可」**をタップ
4. ワークアウトが開始される
5. 画面表示を確認:
   - 経過時間が1秒ごとに増える
   - 距離が表示される
   - 速度が表示される

#### **ステップ2: 動作確認**
1. その場で **2〜3分間待機**
2. 画面を確認:
   - タイマーが正常に動作している
   - 距離が徐々に増える(室内でも少し増える可能性あり)
   - 最高速度が記録される

#### **ステップ3: ワークアウトの終了**
1. **停止ボタン**(赤い四角)をタップ
2. 確認ダイアログで **「終了」**をタップ
3. サマリー画面が表示される
4. 記録内容を確認:
   - 時間: 2〜3分
   - 距離: XXm
   - 平均速度: X.X m/s
   - 最高速度: X.X m/s

#### **ステップ4: データ送信の確認**
1. Xcodeのコンソールで以下のログを確認:
   ```
   🛑 ワークアウト終了
   📊 総距離: XXXm, 最高速度: X.Xm/s
   📍 記録したポイント数: XX
   📤 iPhoneへデータ送信開始...
   ✅ WatchConnectivity準備完了 - データ送信
   📡 iPhone到達可能 - リアルタイム送信を試みます
   ✅ リアルタイム送信成功
   ```

2. **「完了」ボタン**をタップ

#### **ステップ5: iPhoneで確認**
1. iPhoneアプリで **「セッション」タブ**を開く
2. 新しいセッションが追加されているか確認
3. セッションをタップして詳細を確認
4. **「ポジショニング」タブ**で軌跡を確認
5. **「ヒートマップ」タブ**でヒートマップを確認

### **✅ 成功基準:**
- [ ] ワークアウトが正常に開始・終了する
- [ ] タイマーが正確に動作する
- [ ] GPSポイントが記録される(10ポイント以上)
- [ ] データがiPhoneに送信される
- [ ] iPhoneでセッションが表示される

## 🏃‍♂️ テスト3: 屋外での実際のワークアウトテスト (所要時間: 15分)

**目的:** 実際のGPS計測とヒートマップ生成の精度を確認

### **事前準備:**
- 近くの公園やグラウンドに移動
- 天気が良好(GPS精度向上のため)
- Apple Watchを装着

### **手順:**

#### **ステップ1: フィールドの登録(オプション)**
1. iPhoneアプリで **「フィールド」タブ**を開く
2. **+** ボタンをタップ
3. フィールド設定画面で:
   - 名前を入力 (例: 「XX公園」)
   - 地図上でフィールドの4隅をタップして設定
   - **「保存」**をタップ

#### **ステップ2: ワークアウトの開始**
1. Apple Watchでアプリを起動
2. **「開始」ボタン**をタップ
3. GPSが安定するまで10〜20秒待つ
4. 「距離」が少しずつ増え始めたら準備完了

#### **ステップ3: 移動パターン**
以下のパターンで移動してヒートマップをテスト:

**パターンA: 直線往復** (3分)
1. まっすぐ走る(約50m)
2. 戻ってくる
3. これを3回繰り返す

**パターンB: 円形移動** (3分)
1. 円を描くように走る(半径約20m)
2. 同じ場所を3〜4周する

**パターンC: ランダム移動** (3分)
1. ランダムに方向を変えながら走る
2. エリア全体を使って移動

#### **ステップ4: ワークアウトの終了**
1. 合計10〜15分走った後、**停止ボタン**をタップ
2. **「終了」**を選択
3. サマリー画面で記録を確認:
   - 距離: 500m以上
   - 最高速度: 3.0 m/s以上(走った場合)
   - GPSポイント数: 100ポイント以上

#### **ステップ5: ヒートマップの詳細確認**
1. iPhoneで新しいセッションを開く
2. **「ポジショニング」タブ**:
   - 移動軌跡が青い線で表示される
   - スタート地点(緑)とゴール地点(赤)が表示される
   - 実際の移動パターンと一致しているか確認
3. **「ヒートマップ」タブ**:
   - パターンAの場合: 直線上に赤いエリアが表示される
   - パターンBの場合: 円形に赤いエリアが表示される
   - パターンCの場合: 広範囲に色分けされたエリアが表示される
4. **「統計」タブ**:
   - 総距離が実際の移動距離と近いか確認
   - 平均速度・最高速度が妥当か確認

### **✅ 成功基準:**
- [ ] GPSポイントが100ポイント以上記録される
- [ ] 移動軌跡が実際の移動パターンと一致する
- [ ] ヒートマップが滞在エリアを正しく表示する
- [ ] 色分けが適切(青→緑→黄→赤)
- [ ] 総距離が実際の移動距離の±10%以内

## ⚠️ トラブルシューティング

### **問題1: WatchConnectivity未初期化**
**症状:** テスト送信で「WatchConnectivity未初期化」と表示される

**対処方法:**
1. 両方のアプリを完全に終了(ホームボタン2回押し→上にスワイプ)
2. iPhoneを再起動
3. Apple Watchを再起動
4. iPhoneとApple Watchのペアリング状態を確認
5. 再度テスト

### **問題2: GPSポイントが記録されない**
**症状:** ワークアウト終了後、GPSポイント数が0または非常に少ない

**対処方法:**
1. 屋外でテスト(GPS精度向上)
2. ワークアウト開始後、30秒ほど待ってから移動開始
3. 高い建物や木の下を避ける
4. Apple Watchの位置情報設定を確認

### **問題3: データがiPhoneに届かない**
**症状:** ワークアウト終了後、iPhoneにセッションが表示されない

**対処方法:**
1. iPhoneアプリを再起動
2. Xcodeのコンソールでログを確認
3. 「キューイング送信」の場合、数分待つ
4. iPhoneとApple Watchが近くにあるか確認

### **問題4: ヒートマップが表示されない**
**症状:** セッション詳細画面でヒートマップタブが空白

**対処方法:**
1. GPSポイントが10ポイント以上あるか確認
2. フィールドが設定されているか確認
3. アプリを再起動
4. セッションを開き直す
